For Slippi players

melee-combos

Finds the best punishes in your Slippi replays, learns which ones you like as you rate them, and turns your favourites into videos.

Download from GitHub About the app

Needs Windows and Slippi Launcher. Free, open source, about 120 MB.

Before you start

In Slippi Launcher → Settings, make sure your replay folder and Melee ISO are set. If you've never watched a replay in Slippi Launcher, watch one once: that installs the replay player the app uses.

Set it up

  1. Download the app

    On the GitHub page, under Assets, click melee-combos_windows_amd64.exe.

  2. Give it its own folder

    Make a new folder, for example Documents\melee-combos, and move the file there. The app saves its data next to itself.

  3. Double-click it

    Windows will probably show "Windows protected your PC". Click More info, then Run anyway. It shows this for any app that isn't signed with a paid certificate.

  4. Confirm your connect code

    It guesses your code from your replays. Press Enter if it's right, or type yours.

  5. Let it read your replays

    The first time, it goes through every replay you have: a few minutes per thousand. After that it only reads new games and starts in seconds.

The menu

You've rated 0 punishes.
  1  Rate punishes
  2  Watch my top 20 in Dolphin
  3  Make videos of the punishes I rated great
  4  Make my ratings package (to send back)
  5  Check for new replays
  q  Quit
>
1
Rate a batch of 40. The more you rate, the better it gets at finding the ones you like.
2
Watch what it currently thinks are your 20 best.
3
Makes 1080p videos of everything you rated great, in out\clips. The first time, it downloads ffmpeg (about 200 MB). Each clip takes about 40 seconds.
4
Packs your ratings to send back. See below.
5
Reads games you've played since you opened the app.

Rating punishes

A Dolphin window plays one punish at a time. Click back on the app's black window so it hears your keys, then press:

xGreat
gGood
bBad
sSkip
rReplay
qStop for now
After b, say why: 1 repetitive 2 opponent was acting 3 something else

Rate the boring ones honestly too: a "bad" teaches it as much as a "great". You can stop any time, and your ratings are saved as you go.

Sending your ratings back

Pick 4. The app makes ratings-YOURCODE.zip next to itself and opens the folder. Send that file to whoever gave you the app. If it's over Discord's 10 MB limit, upload it to Google Drive and send the link.

ratings-YOURCODE.json Your ratings and the numbers used to rank each punish (damage, hits, kill, movement). No folder paths and no opponent names. This part gets built into the next version of the app, so everyone's ranking improves.
replays\ Only the games your rated punishes come from, so the ranking can be recomputed when it improves. They show your opponents' tags, so they stay private and are never published.

Updating

Download the new version and replace the old file in the same folder. Your ratings and replay data stay where they are. New versions also include everyone else's ratings.

If something goes wrong

It says the playback Dolphin wasn't found

Open Slippi Launcher and watch any replay once. That installs the replay player. Then start the app again.

It says the replay folder or Melee ISO wasn't found

Set both in Slippi Launcher's settings, then start the app again.

Pressing keys does nothing while rating

The Dolphin window has focus. Click on the app's black window and press the key again.

The window closed right away

It may have been moved out of its folder or blocked by antivirus. Put it back in its own folder and run it again; if your antivirus quarantined it, allow it there.

It picked the wrong connect code

Delete config.json in the app's folder and start the app again. It will ask for your code.
